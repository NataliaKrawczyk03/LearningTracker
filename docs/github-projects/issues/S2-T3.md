## Opis

`src/api/client.ts`: `request<T>(method, path, body?)` dokleja nagłówek Authorization, parsuje JSON i rzuca `ApiError(status, detail, fieldErrors)`, gdzie `fieldErrors` to mapa pole → komunikat z odpowiedzi 422. Odpowiedź 401 czyści token i przenosi na `#logowanie`. `src/auth/token.ts` zapisuje token w localStorage (`lt_token`). `src/api/types.ts`: `User`, `Goal`, `Entry`, `DaySummary`, `WeekSummary`, `Streak` według `docs/api.md`. Moduły `auth.ts`, `goals.ts`, `entries.ts`, `stats.ts` z typowanymi funkcjami.
