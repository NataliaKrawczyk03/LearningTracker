## Opis

Przenieść kod do pakietu `app/`: `app/main.py` tworzy aplikację FastAPI, `app/config.py` czyta przez pydantic-settings `DATABASE_URL`, `JWT_SECRET`, `CORS_ORIGINS` z wartościami domyślnymi do pracy lokalnej, `app/routers/health.py` przejmuje `/health`. Plik `backend/main.py` zostaje punktem wejścia dla Vercel (`from app.main import app`). Dodać `.env.example` z nazwami zmiennych bez wartości.
