## Opis

Zmienić `main.js`, `api.js`, `api.test.js` na `.ts` i poprawić ścieżkę w `index.html`. Dodać `typescript` i `typescript-eslint`, `tsconfig.json` w trybie `strict`, plik `src/vite-env.d.ts` z typem `VITE_API_URL`, `vite.config.ts`. W `eslint.config.js` włączyć `tseslint.configs.recommended`. Skrypty: `lint`, `typecheck` (`tsc --noEmit`), `test`, `build`. Zapytać prowadzącego, czy TypeScript zamiast JavaScriptu jest w porządku, i wpisać odpowiedź w opis PR.
