## Opis

Dla każdego endpointu z „Ustaleń” opisać: metodę, ścieżkę, czy wymaga logowania, przykładowe body i odpowiedź JSON oraz kody błędów. Wspólny format błędów: `{"detail": "tekst po polsku"}` dla 400, 401, 404 i 409, a dla 422 domyślny format FastAPI (lista z `loc` i `msg`). Daty jako `YYYY-MM-DD`, minuty jako liczby całkowite, nazwy pól w snake_case.
