## Opis

Uruchamiany przy push do main ze zmianami w `backend/**` albo w samym pliku workflow, plus `workflow_dispatch`. Kroki: checkout, setup-uv, `uv sync`, migracje (S3-N2), `npm i -g vercel`, `vercel pull --yes --environment=production`, `vercel build --prod`, `vercel deploy --prebuilt --prod` z zapisaniem adresu. Na koniec smoke test: `curl --retry 5 --retry-delay 5 -f <adres>/health` i sprawdzenie, że odpowiedź zawiera `"db":"ok"`. Workflow jest czerwony, jeśli API nie wstanie.
