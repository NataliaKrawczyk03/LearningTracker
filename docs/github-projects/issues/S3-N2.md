## Opis

GitHub → Settings → Secrets: `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID`, `DATABASE_URL` (do migracji w workflow). Vercel → Environment Variables: `JWT_SECRET` (losowe 64 znaki), `CORS_ORIGINS`. Zmienna repozytorium `VITE_API_URL`. W `vercel.json` wyłączyć automatyczne deploye z Gita (`"git": {"deploymentEnabled": false}`), bo od teraz deployuje workflow. Razem z Martyną dodać do `deploy-backend.yml` krok `uv run alembic upgrade head` przed deployem.
