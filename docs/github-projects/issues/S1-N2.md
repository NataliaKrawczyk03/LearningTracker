## Opis

Natalia zakłada konto Vercel przez GitHub (jeden właściciel projektu na zespół). Import repo, Root Directory = `backend`. W Vercel → Storage utworzyć bazę Neon Postgres (plan Free) i podłączyć ją do projektu. Vercel sam doda `DATABASE_URL`. W Neon założyć gałąź `dev` do pracy lokalnej i przekazać jej adres zespołowi poza repo (prywatna wiadomość albo menedżer haseł).
